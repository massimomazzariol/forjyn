# ForJyn Screenshot Checklist

Screenshots should be captured manually before a public release.

Use only clean demo state:

- no personal paths visible
- no private content photos
- no unreviewed generated outputs
- no runtime cache or model artifacts
- no training in progress

Suggested future files:

- `forjyn-gui.png`
- `reference-generator.png`

Do not commit screenshots until they are intentionally selected for public documentation.
